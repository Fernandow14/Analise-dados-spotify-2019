📊 Análise de Dados com Python — Spotify Top 50 2019

Projeto acadêmico desenvolvido com foco na aprendizagem e prática de Análise de Dados com Python, utilizando um conjunto de dados do Spotify Top 50 de 2019.
A análise foi realizada no Google Colab e explora características das músicas, artistas, gêneros, popularidade e atributos musicais por meio de manipulação de dados, cálculos estatísticos e visualizações.

🎯 O objetivo deste projeto é aplicar conceitos fundamentais de análise exploratória de dados com Python, praticando:
- importação e leitura de arquivos CSV;
- exploração e compreensão dos dados;
- limpeza e preparação da base;
- renomeação de colunas;
- filtragem e seleção de informações;
- agrupamentos e cálculos estatísticos;
- análise de correlação;
- criação de gráficos;
- interpretação dos resultados.

🔎 Perguntas analisadas
Durante o projeto, foram exploradas as seguintes questões:
1. Qual artista possui a música com maior popularidade?
2. Quais são os 5 artistas mais frequentes no Top 50?
3. Qual música possui o maior índice de dançabilidade?
4. Qual é a música mais longa e qual é a mais curta?
5. Qual é a distribuição de popularidade das músicas?
6. Qual artista possui a maior média de energia?
7. Qual é a média de batidas por minuto (BPM)?
8. Quais músicas possuem os maiores e menores índices de positividade?
9. Qual é a correlação entre energia e volume?
10. Como os gêneros musicais estão distribuídos no conjunto de dados?

📈 Principais resultados
Alguns resultados identificados durante a análise:
- Billie Eilish aparece com o maior índice de popularidade da base: 95.
- Ed Sheeran é o artista mais frequente, aparecendo 4 vezes entre as 50 músicas.
- Talk, de Khalid, apresenta o maior índice de dançabilidade: 90.
- A popularidade média das músicas é de 87,5.
- Katy Perry apresenta a maior média de energia entre os artistas analisados: 88.
- A média de batidas por minuto é de aproximadamente 120,06 BPM.
- Sucker, dos Jonas Brothers, apresenta o maior índice de positividade: 95.
- Money In The Grave, de Drake, apresenta o menor índice de positividade: 10.
- A correlação entre energia e volume é de aproximadamente 0,67, indicando uma relação positiva entre essas variáveis.
- Os gêneros com maior presença na base são dance pop (8 músicas), pop (7 músicas) e latin (5 músicas).
